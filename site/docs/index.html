GETTING STARTED

Meet your workspace.

Try the browser demo with a sample Haxe project. The offline sample keeps edits in browser storage. In a connected demo, files and tools run on the workspace session.

On your desktop

Get packaged builds from GitHub Releases, or follow the source-build steps below.

1. Install Ash CLI

On macOS or Linux, use the official Ash installer, then load its PATH settings:

curl -fsSL https://ash.rayzor.tech/install.sh | sh
. "$HOME/.ash/env"
ash --version
Windows (PowerShell)
irm https://ash.rayzor.tech/install.ps1 | iex

Open a new terminal and check ash --version. Use Git Bash with a Visual Studio developer environment for the source-build commands.

2. Compile RayDE

Install Haxe 4.3.6 and clone RayDE:

git clone https://github.com/rayzor-blade/RayDE.git
cd RayDE

Complete the one-time source dependency setup, which requires Rust, CMake, a C/C++ compiler, Git and Python. Then compile the editor and stage its native libraries:

ASH="$(command -v ash)" scripts/rayde.sh --build

3. Run or build with Ash

Run the compiled editor with Ash CLI:

ash bin/rayde.hl

To build a native AOT executable:

ash --build bin/rayde bin/rayde.hl
./bin/rayde

On Windows, name the output bin/rayde.exe. Keep the native libraries beside the executable.

Open a project file or a folder workspace from Welcome. RayDE restores your windows and tabs the next time you launch it.

# Problems, Output and Terminal

Use the bottom toolbar to open a panel. Closing the panel leaves terminal sessions running and preserves Output text and scroll position.

## Problems

Problems lists diagnostics from language support and the last build. Select a problem to open its file at the reported line. Hover an underlined range in the editor to read its message.

## Output

Choose a channel to read build logs or extension messages. Output displays ANSI colors and text formatting; copying gives you plain text without escape sequences. A notification's **Show Output** action opens the relevant channel.

The status bar shows when an extension is starting or preparing a command. Its view shows loading feedback while content is unavailable; a failed or stopped view offers **Show Output**.

## Terminal

The integrated terminal runs your shell. Configure profiles and terminal options in **Settings > Terminal**. Hiding the panel does not stop running commands.

In a browser workspace, the shell and profiles belong to the session host. Terminal shows startup progress and reconnect errors; it is available when the session allows execution. After losing the session connection, start a new terminal when connected again.
